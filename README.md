# Lab 9: Collections

## Introduction

We are developing a new programming language and have implemented several collections, along with operations for processing their contents.

However, the current design makes it difficult to apply the same operations to different collections. Your task is to identify these limitations and improve the design, paying particular attention to the interfaces between components.

The exercises are divided into two packages: `basic` and `extended`. Start with the basic exercises and complete them in order, as each introduces new requirements that may reveal limitations in your previous design.

Do not use Java's collection classes or generics. For this lab, we are implementing our own collections.
